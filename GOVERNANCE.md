# Governance

UIport is created and maintained by Lorran Hippolyte, with development and maintenance by LuminaSoft. It is shared with the AI Coders Academy community; community credit does not imply ownership of this repository or responsibility for releases.

Lorran decides project scope, merges, release approvals and moderation. Contributors may propose changes through issues and pull requests. Significant behavior changes should describe compatibility and test evidence before implementation.

The project is MIT licensed, accepts external contributions and makes no support SLA commitment. Releases follow semantic versioning; during 0.x, minor releases may contain breaking changes described in the changelog.

Publication uses a reviewed commit and a protected release environment. Maintainer approval is required for release. Secrets and personal sessions must never be committed.
